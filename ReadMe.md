Project Name: Alumni Connect Portal-Student Module

Description:
Developed the backend for the Student Module of a Full Stack Alumni Connect Portal using SpringBoot,MySql and JWT-based authentication.Designed and implemented RESTful APIs to handle student registration,login,profile management,and secure data communication with the frontend.

TechStack
Spring Boot,Spring Security(JWT),MySQL,Spring Data JPA, Restful APIs,Postman.

Key Responsibilities:
Built secure authentication and authorization using Spring Security and JWT.
Created REST APIs for student registration,login and profile data retrieval/update
Integrated MySQL database with Spring Data JPA for persistent data storage.
Implemented file upload APIs for student profile picture and resume management using MultipartFile.
Developed a profile update service to store student details such as headline,about,education and skills in a separate table.
Handled token-based access for all protected student endpoints.
Tested and validated APIs using Postman and integrated with React frontend via Axios.

Outcome:
Enabled a secure and scalable backend foundation for the portal, improving authentication reliability and ensuring seamless data exchange between students and the frontend interface.
